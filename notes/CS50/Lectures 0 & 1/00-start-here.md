## How to use this refresher

**If you have 15 minutes:** skim the C syntax reference, read the common mistakes, and try practice questions 5–10.

**For a fuller review:** read the two lecture notes, then attempt the practice without the answer key. Run the small programs yourself. Return to whichever topics you could recognize but could not explain.

**While taking lecture 2:** keep the syntax reference nearby, especially the sections on loop boundaries, types, and functions.

## Ready to return to arrays?

- [ ] I can explain how the same bits can represent different kinds of data.
- [ ] I can describe an algorithm before writing code.
- [ ] I can save, compile, and run a C program.
- [ ] I can choose a type and the corresponding `printf` format code.
- [ ] I can explain `=` versus `==` and `&&` versus `||`.
- [ ] I can trace a loop that counts from `0` to `n - 1`.
- [ ] I can write an input-validation loop.
- [ ] I can distinguish a function's arguments, parameters, and return value.
- [ ] I understand local scope and passing an integer by value.
- [ ] I can spot integer division and understand why a cast's position matters.

## Scope and conventions

These are original study explanations and examples, with topic coverage checked against the current [CS50x Week 0 outline](https://cs50.harvard.edu/x/weeks/0/) and [Week 1 outline](https://cs50.harvard.edu/x/weeks/1/) on September 14, 2026. The order and demonstrations may differ from the edition you watched. See the official [Lecture 0 notes](https://cs50.harvard.edu/x/notes/0/) and [Lecture 1 notes](https://cs50.harvard.edu/x/notes/1/) for the course's own presentation.

The emphasis is on lectures 0–1. A short preview connects those foundations to arrays; a few extra syntax items are explicitly marked as optional. This is not a full C language reference.

**Code convention:** blocks labeled **Complete program** can be saved as a `.c` file. Other C blocks are fragments to place inside an appropriate program. Programs using `cs50.h` assume the CS50 library is installed and linked; the course environment already provides it. Standard C examples use C11-compatible syntax.
